\chapter{Team-Scale DCF}

\section{Shared CLAUDE.md Standards}

Teams should maintain consistent CLAUDE.md structures:
\begin{itemize}
    \item Project context all team members need
    \item Architectural decisions and rationale
    \item DCF checkpoint requirements
    \item Code review standards
\end{itemize}

\section{Skill Libraries}

Custom skills for team workflows:
\begin{itemize}
    \item \texttt{/deploy-staging}: Team deployment process
    \item \texttt{/review-security}: Security-focused review
    \item \texttt{/update-docs}: Documentation refresh workflow
\end{itemize}

\section{Knowledge Propagation}

\begin{itemize}
    \item Use Claude Code to generate onboarding documentation
    \item Have new team members interact with Claude Code to explore codebase
    \item Capture architectural decisions in CLAUDE.md as they're made
\end{itemize}
