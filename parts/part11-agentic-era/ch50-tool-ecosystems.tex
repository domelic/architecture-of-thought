\section{DCF Principle: Tools Are Thinking Extensions}

Each tool expands what ``thinking with AI'' can accomplish:
\begin{itemize}
    \item Serena provides symbolic code understanding (not just text matching)
    \item Playwright enables verification against real web interfaces
    \item Context7 provides up-to-date documentation as cognitive context
\end{itemize}

\section{Evaluating Tool Usage}

When the agent uses tools, apply DCF:
\begin{itemize}
    \item Was that the right tool for this task?
    \item Did the tool output get interpreted correctly?
    \item Should I verify the tool's output independently?
\end{itemize}
