\chapter{Memory Systems as Cognitive Infrastructure}

Claude Code maintains several memory layers:

\section{CLAUDE.md (Project Memory)}

Lives in your project root. Contains project-specific instructions, conventions, context. Loaded automatically at session start.

\emph{DCF Application}: This is your externalized project cognition. Maintain it deliberately.

\section{User Memories}

Persistent across all projects. Stores preferences, patterns, learned context.

\emph{DCF Application}: Your cognitive profile. The AI learns how you think.

\section{Conversation Context}

Current session's accumulated understanding. Automatically summarized when limits approached.

\emph{DCF Application}: The active working memory of your collaboration.

\section{Serena/MCP Server Memories}

Tool-specific persistent storage. Project onboarding, architectural notes.

\emph{DCF Application}: Specialized cognitive modules for different tools.
