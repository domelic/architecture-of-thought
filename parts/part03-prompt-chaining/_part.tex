\part{Prompt Chaining as Cognitive Architecture}

\begin{quotebox}
\textbf{Historical Context:} This section describes manual prompt chaining---a foundational technique from the conversational era. In agentic systems like Claude Code, much of this happens automatically. Understanding the principles remains valuable for: (1) evaluating whether the agent's automatic chaining is correct, (2) intervening when automatic approaches fail, and (3) working with simpler LLM interfaces that don't support agents.
\end{quotebox}
